Information collected automatically:

  • General usage patterns (pages visited, features used)
  • IP address and approximate geographic location

3. How We Use Your Information

We use your information solely to:

  • Provide, operate, and improve the AutoBooks AI service
  • Process your transactions and financial data

We do not use your financial data for advertising, profiling, or any purpose other than providing the Service.

4. Data Storage & Security

Your data is stored securely using Supabase, a SOC 2 Type II compliant database infrastructure. We implement the following security measures:

  • AES-256 encryption for data at rest
  • TLS 1.3 encryption for all data in transit
  • Row-level security policies on all database tables
  • Regular security audits and vulnerability assessments
  • Strict access controls — only you can access your financial data

AutoBooks AI uses artificial intelligence to analyze your financial data and provide insights. When the AI Advisor feature is active:

  • Your transaction data is sent to Anthropic's Claude API for processing
